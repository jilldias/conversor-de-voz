Este projeto foi desenvolvido utilizando apenas recursos nativos do navegador, sem dependências externas:
Lógica principal implementada em JavaScript puro.

Manipulação de eventos (addEventListener) e elementos da página.
DOM API (Document Object Model)
Seleção e interação com elementos HTML através de document.querySelector e document.getElementById.
Atualização dinâmica de opções no <select> e captura de inputs do usuário.
Web Speech API (SpeechSynthesis)
Utilização de SpeechSynthesisUtterance para conversão de texto em fala (Text-to-Speech).
Controle das vozes disponíveis com speechSynthesis.getVoices().
Evento onvoiceschanged para detectar quando as vozes ficam disponíveis.
Execução da fala com speechSynthesis.speak().
